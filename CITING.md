# Citing

If you use AALpy-extra, please cite AALpy, see [Citing](README.md#citing) in the README.
Additionally, please cite the publication of each extension that you use:

| Extension | Publication |
|---|---|
| Policy-guided active Alergia / probabilistic black-box reachability checking (`aalpy_extra.learning_algs.stochastic_passive`) | [Aichernig and Tappler, FMSD 2019](#probabilistic-black-box-reachability-checking) |
| L#-square learner for incomplete teachers (`aalpy_extra.learning_algs.incomplete_teacher`) | [Laumen, Snel, and Vaandrager, CAV 2026](#l-square-learning-from-incomplete-teachers) |
